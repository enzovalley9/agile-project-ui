# BMAD Project UI

A read-only web interface for exploring BMAD Method project files.

## Status

Discovery and design. The application has not been implemented. The technology stack, visual direction, distribution model, and license are still to be decided.

This repository is private during preparation. A future open-source release is planned; changing visibility and choosing a license are separate decisions.

## Product principles

- BMAD text files are the sole source of truth for project data.
- The first version is read-only: it will not edit artifacts or start agents or workflows.
- No external database or parallel authoritative data store.
- An independent visual identity, with traceable information from source files.

This is an independent project and does not imply endorsement by the BMAD Method maintainers.
